# 🏗️ One-Bedroom Apartment Floor Plan & 3D Design (AutoCAD)

## 📌 Overview

This project was developed as part of the **CSE200 – Computer Aided Engineering Drawing** course at **East West University**.

The project focuses on designing a **2D floor plan** of a one-bedroom apartment (25 ft × 25 ft) and transforming it into a fully detailed **3D architectural model** using **AutoCAD**. It demonstrates how a set of engineering constraints (room sizes, wall thickness, wall height, and roof dimensions) can be translated into an accurate and realistic structural design.

## 📐 Design Specifications

- Total apartment area: **25 ft × 25 ft**
- Bedroom (interior): **12 sqft**
- Kitchen, washroom, and lounging area arranged around the bedroom
- Inner walls: **5 inches** thick
- Outer walls: **10 inches** thick
- Wall height: **11 ft**
- Roof: **10 inches** thick, matching the full outer length & width of the apartment (including outer walls)

## 📐 Project Features

- 2D floor plan design
- 3D model visualization (with roof and without roof)
- Proper room layout planning (bedroom, kitchen, washroom, lounge)
- Accurate scaling and proportions
- Basic architectural elements (walls, doors, roof)

## 🧠 Concepts Used

- Computer Aided Design (CAD)
- Engineering Drawing Principles
- 2D to 3D Transformation
- Spatial Visualization
- Design Accuracy and Scaling

## 🎯 Objectives

- To understand the fundamentals of AutoCAD
- To design a structured and well-planned one-bedroom apartment layout
- To convert a technical 2D floor plan into a 3D visualization
- To improve spatial and architectural understanding
